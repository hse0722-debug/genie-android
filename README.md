# 지니 리모컨 — 작업 코드 10.0.4

시작 준비의 시트 요청을 통합하고 불필요한 홈페이지 이동과 중복 로그아웃을 줄였습니다. Google 시트에서 전체·헬퍼별 중단과 중단 확인 후 남은 계정 갱신을 지원합니다. 기존 결제·다운로드 순서와 리모컨 디자인을 유지합니다.

## 적용 순서

1. 모든 기존 사용자가 리모컨에서 **수동 중단**합니다. 이전 버전은 새 원격 중단 명령을 확인하지 않습니다.
2. 관리자만 접근하는 별도 비공개 관리 시트의 Apps Script에서 Code.gs를 교체·저장합니다.
3. 관리 시트를 새로고침하고 **지니 연동 → 1. 초기 설정 → 원격제어 탭 만들기**를 실행합니다.
4. **배포 관리 → 기존 웹 앱 수정 → 새 버전 → 배포**를 선택합니다. 소유자로 실행·모든 사용자 접근 방식입니다. 같은 배포를 수정하면 /exec 주소가 유지됩니다.
5. 사용자는 중단 후 지니 페이지를 새로고침하고 작업 코드 **10.0.4**를 확인합니다. 기존 10.x 실행기는 재설치하지 않습니다.

## 관리자 중단과 계정 갱신

리모컨제어 탭에서 전체 또는 정확한 헬퍼 이름 행의 명령을 **실행 허용 / 중단 / 중단 후 계정 다시 불러오기**로 지정합니다. 전체·헬퍼 중 하나라도 중단이면 시작할 수 없습니다. 실행 허용은 자동 재시작하지 않습니다.

계정 배정 변경 전 중단을 요청하고 리모컨상태의 **각 기기별 중단 확인과 마지막 확인 시간**을 확인합니다. 이후 계정 배정을 수정하고 중단 후 계정 다시 불러오기를 선택합니다. 기기별 갱신 완료를 확인한 뒤 실행 허용으로 바꾸고 사용자가 직접 시작합니다. 사용자가 리모컨의 **■ 중단 후 남은 계정 다시 불러오기**를 눌러도 됩니다.

약 5초 간격으로 확인하며 네트워크 지연이 추가됩니다. 종료·절전·오프라인 기기의 오래된 상태는 중단 확인으로 간주하지 마세요. 이미 제출된 결제나 시작된 다운로드를 취소하지는 않습니다.

갱신 시 현재 실행에서 이미 다음으로 넘어간 계정은 제외합니다. 중단한 현재 계정은 새 배정에 포함되면 다시 불러오므로 일부 작업이 재시도될 수 있습니다. 미기록 결과는 비밀번호 없이 별도 보관하며 재시도·내보내기를 지원합니다. 다른 기기로 제어권이 넘어가면 진행 중 갱신 결과를 적용하지 않습니다. 최종 결제 직전에는 계정 잠금과 로그인 세션을 캐시 없이 확인합니다.

## 기존 시트 규칙과 동시 사용

D열 아이디와 같은 행 J열 실제 비밀번호를 사용하며 비밀번호를 리모컨·로그에 표시하지 않습니다. B열 시간·C열 헬퍼를 선택하며 gid로 여러 탭을 지원합니다. 별도 연결 코드·인증은 없습니다. E=다운로드, F=곡, G=뮤비, H=앨범, I=가수의 o/x 기록을 유지합니다. **다운로드 o는 다운로드 시작 감지이며 파일 저장 완료 확인은 아닙니다.** 시드가 없는 항목은 제외합니다.

모든 헬퍼는 같은 Apps Script 프로젝트의 웹 앱을 사용하세요. 동일 프로젝트는 파일·탭이 달라도 같은 계정의 중복 실행을 잠금으로 방지합니다. 다른 프로젝트끼리는 잠금을 공유하지 않습니다.

## 검증 범위

10.0.4 준비 과정에서 가짜 시트 기반 원격 제어·계정 갱신·결과 보관·제어권 변경과 기존 로그인·결제 순서·다운로드 중복 방지·실행기 회귀 테스트를 통과했습니다. 이번 업로드 재개 과정에서는 자동 테스트를 다시 실행하지 않았습니다. 실제 결제 성공·Android 기기·실제 Apps Script 배포 검증은 수행하지 않았습니다. 실제 기기의 개선 후 시작 시간도 아직 측정하지 않았습니다.
