# 지니 리모컨 — 작업 코드 10.0.2

**같은 행의 D열 아이디와 J열 실제 비밀번호를 짝지어 로그인합니다.** D3↔J3, D4↔J4 방식입니다. 비밀번호 1·2 선택 방식과 리모컨 입력칸은 제거했습니다. 리모컨·진행표·작업 로그에는 실제 비밀번호를 표시하지 않습니다.

## 적용 순서

1. 작업을 중단하고 계정 시트 J열에 각 D열 계정의 실제 비밀번호를 입력합니다. J열을 일반 텍스트로 지정하면 앞자리 0과 특수문자를 보존하기 좋습니다. 기존 1/2 선택 번호는 더 이상 쓰지 않습니다.
2. Apps Script Code.gs를 새 파일로 교체·저장하고 배포 관리 → 수정 → 새 버전 → 배포로 갱신합니다. 같은 배포를 수정하면 /exec 주소가 유지됩니다.
3. 지니를 새로고침해 작업 코드 10.0.2를 확인합니다. 기존 10.0.0 실행기는 재설치하지 않습니다.
4. 계정 탭 주소 불러오기 → 시간·헬퍼 선택 → 선택한 계정 불러오기 → 시작합니다. 이전 방식의 목록을 그대로 실행하지 않고 새로 불러오도록 했습니다.

처음 설치하거나 9.0.x인 경우 안내서대로 실행기 10.0.0을 설치합니다. 연결 코드는 없습니다. C열 이름을 중복 없이 읽어 직접 선택하며 B열 시간으로 계정을 고릅니다. J열이 빈 계정은 제외하고 개수를 표시합니다. 시작 직전에도 계정 ID를 기준으로 J열 비밀번호를 다시 확인합니다.

## 결과 기록

E=다운로드, F=곡, G=뮤비, H=앨범, I=가수에 o/x를 기록합니다. 시드가 없는 항목은 공란으로 표시하고 새 결과를 쓰지 않습니다. 다운로드 o는 기존 브라우저 다운로드 시작 감지이며 파일 저장 완료를 보증하지 않습니다. 기존 로그인 세션 확인과 결제·다운로드 흐름을 유지했습니다.

공유 시트와 연결 코드 없는 웹 앱 방식은 그대로입니다. 비밀번호는 시트에서 Apps Script를 거쳐 브라우저로 전달되며 공개 접근 제한을 새로 추가하지 않습니다. 실제 비밀번호를 GitHub에 저장하지 않습니다. 결과 쓰기 요청에는 계정 ID와 결과만 포함합니다.

행별 비밀번호 연결, 앞자리 0, 응답 순서가 바뀐 경우 ID 매칭, 화면 비표시, J열 누락, E~I 기록 재시도와 로그인·결제·다운로드 회귀를 모의 검증했습니다. 실제 Apps Script 배포와 구매·Android 실기기는 미검증입니다.
