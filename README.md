## 이미 설치했다면

10.0.0 실행기는 재설치하지 않습니다. 리모컨에서 중단하고 지니를 새로고침하면 작업 코드 10.0.1이 적용됩니다. **Apps Script의 Code.gs를 새 파일로 교체하고 저장 → 배포 관리 → 수정 → 새 버전 → 배포**해야 합니다. 같은 배포를 갱신하면 웹 앱 주소가 유지됩니다. 연결 코드 발급·입력은 필요 없습니다.

9.0.x 실행기는 Apps Script 접속 권한 추가 때문에 10.0.0 실행기로 한 번 교체해야 합니다. 이전 9.0.x release.json은 보존됩니다.

## 처음 설치한다면

1. 계정 시트의 A~J열을 맞추고 J열에 비밀번호 번호 1/2를 입력합니다.
2. 별도의 비공개 관리 시트에서 Apps Script를 열고 Code.gs를 설치합니다.
3. 관리 시트를 새로고침하고 지니 연동 → 초기 설정을 실행합니다.
4. 웹 앱을 실행 사용자: 나 / 액세스: 모든 사용자로 배포합니다.
5. 리모컨 연결 설정에 웹 앱 /exec 주소만 저장합니다.
6. 계정 탭 주소(gid 포함) 불러오기 → 시간·헬퍼 선택 → 계정 불러오기 → 비밀번호 두 개 입력 → 시작합니다.

웹 앱 주소를 아는 사람은 관리자에게 허용된 파일에서 계정·시드 정보를 조회하고 E~I열 결과를 기록할 수 있습니다. 연결 코드나 Google 사용자별 제한은 없습니다. 임의 파일 접근과 E~I 이외의 셀 변경은 허용하지 않습니다. 비공개 시드 파일 자체의 공유 권한은 유지되지만, 필요한 이름·시드는 웹 앱으로 조회됩니다.

## 동작

J열 1/2로 선택하는 실제 비밀번호는 브라우저에만 저장되며 Apps Script/GitHub에는 전송하지 않습니다. 시드가 없는 항목은 공란으로 표시하고 작업하지 않습니다. E=다운로드, F=곡, G=뮤비, H=앨범, I=가수에 o/x를 기록합니다. **다운로드 o는 파일 저장 완료가 아니라 기존 브라우저 다운로드 시작 감지입니다.**

파일·탭·선택 범위를 고정하고, 행이 이동해도 ID를 다시 찾아 기록합니다. 기록 재시도와 다른 기기의 계정 사용 잠금을 유지합니다. 기존 로그인 세션 확인, 결제 단계·딜레이와 다운로드 감지도 유지했습니다.

연결 코드 없이 전체 C열 목록 조회, 시간/헬퍼 선택, J1/J2, E~I 기록, 파일/탭/값 제한, 재시도, 로그인·결제·다운로드 회귀를 모의 검증했습니다. 실제 Apps Script 배포는 사용자가 수행하며 실제 구매·Android 실기기는 미검증입니다.
