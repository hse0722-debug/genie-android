# 지니 리모컨 10.0.0 — Google Sheets + Apps Script

시간·헬퍼별 계정 불러오기, 비밀번호 1·2의 J열 선택, 앨범·곡·뮤비·가수 시드, E~I열 o/x 결과 기록을 지원하는 새 리모컨입니다. 비공개 시드는 관리자 권한의 Apps Script로 읽습니다.

**이번에는 실행기를 10.0.0으로 한 번 교체해야 합니다.** Apps Script 접속 권한이 추가됐습니다. 기존 9.0.x 사용자에게 새 버전을 자동으로 강제하지 않도록 기존 release.json은 유지합니다. 10.0.0 이후 작업 코드는 release-v2.json을 통해 중단 후 지니 새로고침으로 갱신합니다.

## 관리자 순서

1. 계정 탭 A~J열을 정리하고 J열에 1/2를 입력합니다.
2. **별도의 비공개 관리 스프레드시트**를 만들고 그 안의 Apps Script에 Code.gs를 설치합니다. 공유 계정 시트에 스크립트를 설치하지 마세요.
3. 관리 시트를 새로고침하고 지니 연동 메뉴에서 초기 설정과 헬퍼 연결 코드 발급을 실행합니다.
4. 웹 앱을 **실행 사용자: 나 / 액세스: 모든 사용자**로 배포합니다. 요청은 별도의 헬퍼 연결 코드로 검증합니다. 코드 없이 계정·시드 조회나 결과 변경은 할 수 없습니다. 웹 앱 주소와 연결 코드는 함께 공개하지 마세요.
5. 리모컨 연결 설정에 웹 앱 /exec 주소와 해당 헬퍼의 연결 코드를 입력합니다.
6. 계정 탭 주소(gid 포함)를 불러오고 시간·헬퍼 선택 → 선택한 계정 불러오기 → 두 비밀번호 입력 → 시작합니다.

실제 비밀번호는 각 브라우저에만 저장되며 Apps Script나 GitHub에 전송하지 않습니다. 연결 코드는 Apps Script가 해당 헬퍼의 조회·기록을 허용하는 자격 정보이므로 개인적으로 전달하세요.

같은 파일의 탭 추가와 이름 변경은 스크립트 재배포가 필요 없습니다. 별도 계정 파일은 관리 메뉴에서 허용하고 관리자 편집 권한을 부여합니다. 시드 파일과 탭은 스크립트 속성으로 설정합니다.

## 결과 의미와 검증

E=다운로드, F=곡, G=뮤비, H=앨범, I=가수입니다. 시드가 없는 항목은 공란으로 표시하고 새 결과를 쓰지 않습니다. **다운로드 o는 기존 브라우저 다운로드 시작 감지이며 파일 저장 완료를 뜻하지 않습니다.** 기존 결제 단계·딜레이와 로그인 세션 확인을 유지합니다.

연결 코드/파일/탭/헬퍼 제한, J1/J2, 빈 시드, 중복 계정, 행 이동 후 쓰기, 기록 재시도, 다른 기기의 계정 사용 잠금, 리모컨 DOM 조작, 로그인/결제/다운로드 회귀를 모의 검증했습니다. 실제 Apps Script 배포·권한 승인은 사용자가 수행해야 하며, 실제 구매 및 Android 실기기 검증은 하지 않았습니다.

구체적인 설정과 오류 해결은 설치·배포 안내서를 먼저 읽어주세요.
