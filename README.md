# 지니 리모컨 — 작업 코드 10.0.3

연결 설정을 항상 표시하고 비밀번호 안내 영역을 제거했습니다. 작업 대상은 가수·앨범·뮤비·곡 순서의 텍스트로 표시합니다. 버튼은 **▶ 시작 / ■ 중단 / ▷ 넘기기**입니다.

## 적용

모든 사용자 중단 → Apps Script Code.gs 교체·저장 → 배포 관리에서 새 버전 배포 → 지니 새로고침 → 패널 10.0.3 확인 순서입니다. 기존 10.0.0 실행기는 재설치하지 않습니다. 9.0.x는 안내서대로 실행기를 한 번 교체합니다.

## 넘기기

실행 중에는 현재 계정의 확인된 결과를 유지하고 미처리 작업을 x로 기록한 뒤 로그아웃·다음 계정 로그인 확인을 진행합니다. 중단 상태에서는 다음 시작 위치만 저장합니다. 넘긴 계정의 지연 클릭과 로그인 응답, 중복 넘기기 요청은 차단합니다. 이미 완료된 결제나 시작된 다운로드를 취소하지는 않습니다.

## 여러 사람 동시 사용

**관리자 한 명이 배포한 같은 Apps Script 웹 앱 주소를 함께 사용하세요.** 같은 프로젝트의 시트 기록은 LockService로 순서대로 처리하며, 허용된 파일이나 탭이 달라도 동일 계정 아이디는 중복 실행하지 못하도록 잠급니다. 파일·탭·아이디를 다시 대조해 결과를 기록합니다. 프로젝트를 따로 만들면 잠금을 공유하지 못합니다.

서로 다른 계정을 선택해 사용하며 작업 중 헬퍼·시간 배정은 변경하지 마세요. 요청이 몰리면 지연·재시도가 생길 수 있습니다. 여러 실제 기기에서의 부하 검증은 하지 않았습니다.

## 기존 기능

D열 아이디와 같은 행 J열 실제 비밀번호로 로그인하며 리모컨·진행표·로그에 비밀번호를 표시하지 않습니다. 연결 코드는 없습니다. B열 시간과 C열 헬퍼를 선택합니다. E=다운로드, F=곡, G=뮤비, H=앨범, I=가수의 o/x 기록과 로그인 확인·결제·다운로드를 유지합니다. 다운로드 o는 파일 전체 저장 완료가 아닌 브라우저 다운로드 시작 감지입니다. 시드가 없는 항목에는 새 결과를 쓰지 않습니다.

접힌 설정 제거·텍스트 표시 순서·버튼을 DOM 검증했고 중복 넘기기 20건, 넘긴 뒤 지연 결제/로그인 차단, 중단 상태 위치 변경·다음 시작 위치 유지, 여러 탭의 같은 계정 잠금과 기존 결제 회귀를 모의 검증했습니다. 실제 Apps Script 배포·구매·Android 실기기는 미검증입니다.
